# Ремонт Авто · Минск

Статический редизайн СТО на Макаёнка, 11 по визуальному ориентиру VAGMOTORS. Vite + обычные HTML/CSS/JavaScript. Сервер и секреты не требуются.

## Разработка

Node.js 22.12+ или 24 LTS.

```sh
npm ci
npm run dev
```

## Сборка и проверка

```sh
npm run build
npm run preview
```

Сборка в `dist/`, пути относительные: подходит для GitHub Pages в подпапке репозитория. Каталог `dist` нужно публиковать целиком. Публикация в ходе реализации не выполнялась.

Браузерная проверка (при запущенном dev-сервере):

```sh
npx playwright install chromium
npm test
```

Тест использует системный `/usr/bin/chromium`, если он доступен, иначе браузер Playwright. Можно указать `CHROMIUM_PATH` и `TEST_URL`. Проверяет реальные действия: расчёт, количество, удаление, сохранение корзины, текст записи, мобильное меню и отсутствие горизонтального переполнения.

## Контент

Цены редактируются в `src/main.js` (`groups`), тексты и контакты — в `index.html`. Цены из действующего прайса от 09.10.2026, в BYN, «от», только работа для легковых авто. Каждый шиномонтажный комплекс рассчитан на четыре колеса; детали, грузы и вентили отдельно. При обновлении прайса измените также дату ссылки и сезонный блок.

Запись — форма подготовки сообщения, выбор желаемой даты и времени, копирование расчёта и переход в Telegram или Viber. Поиск фильтрует каталог, быстрые наборы добавляют типовые работы. На телефоне доступна панель суммы. Бэкенда отправки заявок нет. Все итоговые работы и стоимость подтверждаются мастером. Корзина сохраняется в localStorage.

[Обзор конкурентов, источники данных и фотографий](docs/research.md).

## Текущая публикация GitHub Pages

Pages настроен на ветку `main`, каталог `/`. Корневой `index.html`, `src/`, `public/fonts/`, `images/`, `favicon.svg` и `.nojekyll` работают как обычный статический сайт, без сборки на GitHub. JS не требует преобразований. Корневые `images/` и `favicon.svg` — копии файлов из `public/`; при замене фотографий синхронизируйте обе папки. Vite-сборка `dist/` также поддерживается для других способов размещения. Ветка `gh-pages` содержит отдельную готовую сборку, но текущие настройки Pages используют `main`.

Переключатель в шапке меняет светлую и тёмную тему всего сайта. Выбор хранится в localStorage (`remont-theme`) и применяется до загрузки стилей. По умолчанию используется тёмная тема. Заголовки — Geologica, основной текст — Golos Text, файлы шрифтов и лицензии находятся в `public/fonts/`.
